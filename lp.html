// userscript manager

TAMPER GORILLA

Run powerful scripts on any website. Convert PDFs, force dark mode, block ads, auto-fill forms — all from one extension with granular permission control.

Free · No account needed
pdf-converter.user.js 
// ==UserScript==
// @name         PDF Converter
// @match        *://*/*
// @grant        GM_download
// ==/UserScript==

const btn = createButton('Save as PDF');

btn.addEventListener('click', () => {
  const opt = {
    margin: '10mm',
    filename: getPageTitle() + '.pdf',
    format: 'A4'
  };
  generatePDF(document.body, opt);
});

// what you can do

Scripts for every workflow

Install community scripts or write your own. TamperGorilla runs them safely with configurable permission levels.

PDF Converter

One-click export of any webpage — articles, invoices, documentation — to a clean, printable PDF.

@grant GM_download

Dark Mode Everywhere

Force dark mode on sites that don't support it. Customisable contrast, brightness, and sepia filters per domain.

@run-at document-start

Ad & Clutter Remover

Strip cookie banners, popups, floating share bars, and intrusive ads using community-curated selector lists.

@grant GM_addStyle

Auto Form Filler

Save field templates and replay them across checkout forms, registrations, and surveys with a single keystroke.

@match *://*/*

Price Tracker

Monitor product prices on Amazon, eBay, and major retailers. Get a browser notification when a price drops.

@grant GM_notification

Auto Translator

Translate selected text or full pages inline without leaving the tab. Supports 40+ languages via a free API endpoint.

@grant GM_xmlhttpRequest

// getting started

Up and running in 60 seconds

1

Install the extension

Add TamperGorilla to Edge or Chrome from the Web Store. No account or email required — install and go.

2

Pick a script

Open the dashboard, browse the built-in script library, or paste any .user.js URL to install from the web.

3

Control permissions

Choose Sandbox, Limited, Standard, or Elevated level per script. Grant only what each script actually needs.

// trust model

You decide what each script can touch

Unlike other script managers that run everything with full access, TamperGorilla lets you assign a permission level per script — isolating untrusted scripts from your data and storage.

Sandbox

No DOM access, no storage, no network

SANDBOX

Limited

Read-only DOM, no cross-origin requests

LIMITED

Standard

Full DOM, script storage, same-origin XHR

STANDARD

Elevated

Cross-origin XHR, notifications, downloads

ELEVATED
