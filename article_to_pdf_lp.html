What it does

Every website

Matches *://*/* — every URL, every protocol. Install once, use on any page you visit.

Strips the noise

Removes ads, nav bars, footers, sidebars, share buttons, cookie banners, newsletter popups, and comments.

Proper A4 layout

20mm margins, Georgia serif body text, structured header with domain, title, byline and date. Page breaks where they should.

Smart extraction

Tries 12+ selectors — article, [itemprop], main — before falling back to the element with the highest text density on the page.

Images preserved

In-article images are kept and resized for print. Inline figures, captions, and code blocks too — nothing important gets dropped.

Zero dependencies

No account, no server, no tracking. @grant none — everything runs locally in your browser, nothing leaves your machine.

How it works
1

Install TamperGorilla

Add TamperGorilla to Edge or Chrome. It's a userscript manager built for MV3 — no compromises, no eval hacks.

2

Install this script

Click "Install Script" above. TamperGorilla detects the .user.js file and adds it to your active scripts instantly.

3

Click PDF on any page

A red PDF button appears bottom-right on every site. Click it — the browser print dialog opens with a clean, ad-free layout ready to save.
